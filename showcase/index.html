The core finding

Each point is one email source. As average detectable cues rise (right), simulated click rate falls (down). The V-Triad AI email ranks 3rd overall, in a tight cluster with the two best-performing real, human-authored phishing sources (ceas08, phishbowl), not an outlier alone in the corner.

The corpus

Ten sources kept strictly segregated, never blended, so cue behaviour and click rate can always be sliced by origin. Loaders and DOIs ship in the repo; the corpora themselves are not re-hosted.

The workday effect

The same agent, reading the same email, at 8am versus 4pm. As modelled fatigue accumulates across the day, susceptibility rises, a within-person effect held here as an honest, bracketed prediction (see §05).

How an agent decides

Every quantity lives on a single [0,1] scale so fatigue is monotone and actually moves outcomes. The decision itself is a per-cue stochastic loop: the agent perceives red flags one by one until suspicion crosses its threshold.

05

How to read these numbers

The honest framing: the version that survives an examiner. Included on the showcase deliberately.

What the result is

A relative ranking of email sources by detectability→susceptibility, under identical controlled conditions. Persuasion-guided AI phishing reaches parity with the best human-authored spear-phishing (ceas08, phishbowl) and clearly outperforms naive AI phishing, that ordering is the finding.

What it is not

The absolute click rates (28–83%) are not population predictions. Verizon's DBIR reports a ~1.4% real-world median; these levels are an artifact of the model's parameterization. Read the rank order, not the percentages.

Replication

Cue extraction ran on gemma4:12b (local). An earlier cross-check on llama-4-scout-17b (hosted) was run before a labelling-validity fix to the V-Triad corpus and is being re-verified, see notebook 07_vtriad_validity_fix.ipynb.

Reproducible & offline

Nothing on this page runs a model. Cue extractions are cached and the simulation is deterministic Python, the entire result set rebuilds from committed data with no GPU and no API key.
